# Project Guidelines & Rules

## Stack
- Environment: Node.js (LTS)
- Track: Frontend AI Engineering

## Conventions
- Follow Conventional Commits format (`chore:`, `docs:`, `feat:`).
- Keep components modular and clean.

## Tech Stack Rules
- **HTML5:** Semantic elements only.
- **CSS3:** Responsive layout using CSS Grid / Flexbox.
- **JavaScript:** ES6+ standards without external heavyweight frameworks.

## Workflow Rules
- Always create dedicated feature branches (`feature/round1-vague`, `feature/round2-precise`).
- Solve merge conflicts by retaining the latest precise specifications (`--ours`).
- Ensure all feature branches are merged into `main` via Pull Requests.
