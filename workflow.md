# Vague vs. Spec-Driven Engineering Drill Analysis

## Executive Summary
This drill highlights the difference between executing tasks based on vague requirements versus precise specifications.

---

## Comparison Matrix

| Aspect | Round 1 (Vague) | Round 2 (Spec-Driven) |
| :--- | :--- | :--- |
| **Requirements Clarity** | Low / Ambiguous | High / Clear Specifications |
| **Code Structure** | Minimal & Basic | Modular, Scalable & Clean |
| **Components Created** | Single Analytics Card | Top Navbar, Analytics Card, Data Table, Tests |
| **Rework Required** | High | Low |
| **Testing** | None | Unit Tests Included (`script.test.js`) |

---

## Key Learnings
1. **Spec-Driven Efficiency:** Clear guidelines reduce back-and-forth iteration time.
2. **Standardization:** Maintaining guidelines in `CLAUDE.md` keeps the repository structured.
3. **Git Workflow:** Isolated branch strategy (`feature/*`) prevents breaking the `main` branch.
